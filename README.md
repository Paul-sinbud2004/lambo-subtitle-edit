# 蓝博字幕编辑器

[English](README.en.md)

一款带双视频对照预览的 SRT 字幕编辑器，使用 Rust + egui 构建。

![图标](assets/icon.png)

## 特点

- 目标视频与可选的参考视频并排播放，共享播放、跳转与时间轴控制；参考视频可设置基线偏移。
- 点击字幕行即可定位到该字幕起始画面；两路预览同步刷新。
- IDE 风格字幕编辑区：行号、彩色时间/文本、时间微调按钮、多行选择与剪切/复制/粘贴。
- 仅播放字幕片段、循环选中字幕片段；默认双路静音，可任选一路出声。
- 查找替换（查找下一个 / 替换当前 / 全部替换），支持中文与英文界面、多种配色与字号设置。
- 字幕可自动加载同名文件，也可手动载入、新建、保存；解码错误会给出提示。

## 用法

```bash
# 直接启动
lambo-subtitle-edit

# 启动时载入目标视频（及其同名字幕）和可选参考视频
lambo-subtitle-edit target.mp4 reference.mp4
```

工具栏图标从左到右依次为：载入目标视频、载入参考视频、关闭参考视频、载入字幕、新建字幕、保存字幕、另存字幕、设置、关于。悬停可查看提示。

- 点击字幕行选中并定位画面；按住 Shift 可范围多选，点击行号可拖动多选。
- 先点选某个时间，工具栏的 `-1 s / -0.1 s / +0.1 s / +1 s` 才会生效。
- 设置中可切换语言、配色、字号和预览字幕颜色。

## 编译安装

依赖：Rust（稳定版）、GStreamer 运行库及含常用编解码器的插件。

```bash
cargo build --release
cargo test
./target/release/lambo-subtitle-edit
```

Arch Linux 用户可通过 AUR 安装：`yay -S lambo-subtitle-edit`。
